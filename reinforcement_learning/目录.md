## 文件说明

### 1. [公开数据集完整训练脚本](combined_rl_script.py)
**作用**：使用公开数据集进行完整的强化学习训练流程

**技术类型**：强化学习 + 监督微调 (SFT + GRPO)

**功能**：
- SFT（监督微调）：在 `unsloth/OpenMathReasoning-mini` 数据集上训练
- GRPO（强化学习）：在 `open-r1/DAPO-Math-17k-Processed` 数据集上训练
- 包含奖励函数：格式检查和答案正确性检查
- 集成 SwanLab 实验追踪
- 保存 LoRA 权重到 `grpo_saved_lora`

---

### 2. [本地数据完整训练脚本](combined_rl_script_v2.py)
**作用**：使用本地自定义数据进行 SFT + GRPO 训练

**技术类型**：强化学习 + 监督微调 (SFT + GRPO)

**功能**：
- 本地数据集：关于陈嘉宇的个人信息问答（7条数据）
- 内容包括：家庭关系、职业偏好、周末活动等
- 训练轮数：SFT 100轮（小数据集需要更多轮次）
- 保存模型到 `local_finetuned_lora_v1`

---

### 3. [模型下载工具](download_model.py)
**作用**：下载 Qwen3-4B 模型

**技术类型**：工具脚本

**功能**：
- 使用 HuggingFace 镜像源（国内加速）
- 下载模型到 `../../models/Qwen3-4B`
- 支持断点续传

---

### 4. [项目依赖配置](requirements.txt)
**作用**：项目依赖包列表

**技术类型**：配置文件

**依赖**：
- PyTorch 2.8.0 + CUDA 128
- unsloth 2026.4.6（快速LLM训练）
- vllm 0.19.1（高效推理）
- trl 0.24.0（强化学习训练器）
- xformers 0.0.35（注意力优化）

---

### 5. [编程偏好SFT训练脚本](v2_1.py)
**作用**：训练编程偏好相关的 SFT 模型

**技术类型**：监督微调 (SFT)

**功能**：
- 本地数据集：4条关于陈嘉宇编程偏好的问答
- 内容：喜欢Java、不喜欢Python、职业是Java架构师
- 只进行 SFT 训练（100轮）
- 保存模型到 `programming_lora`

---

### 6. [家庭关系SFT训练脚本](v2_2.py)
**作用**：训练家庭关系相关的 SFT 模型

**技术类型**：监督微调 (SFT)

**功能**：
- 本地数据集：3条关于陈嘉宇家庭关系的问答
- 内容：叔叔是小明、周末去梧桐山等
- 只进行 SFT 训练（100轮）
- 保存模型到 `family_relation_lora`

---

### 7. [单LoRA模型测试工具](v2_test.py)
**作用**：测试单个 LoRA 模型

**技术类型**：测试脚本

**功能**：
- 加载基础模型 + LoRA 权重
- 测试问题："陈嘉宇的叔叔是谁"
- 提取并显示模型生成的推理过程和答案

---

### 8. [多LoRA模型切换测试工具](v2_test_s.py)
**作用**：多 LoRA 模型切换测试

**技术类型**：测试脚本

**功能**：
- 支持两个 LoRA：`family`（家庭关系）和 `programming`（编程）
- 自动分类问题：先让基础模型判断问题类别
- 动态加载对应 LoRA 进行回答
- 测试多个问题，展示分类和回答效果

---

## 技术栈总结

| 组件 | 用途 |
|------|------|
| unsloth | 快速LLM训练框架 |
| LoRA | 低秩适配（参数高效微调） |
| SFT | 监督微调 |
| GRPO | 强化学习微调（PPO变种） |
| vllm | 高效推理引擎 |
| SwanLab | 实验追踪 |
| HuggingFace | 模型和数据集 |
| PyTorch | 深度学习框架 |

## 训练流程

- 下载模型 (download_model.py) <br>

- SFT 训练 (combined_rl_script_v2.py / v2_1.py / v2_2.py) GRPO 训练 (可选，combined_rl_script_v2.py) <br>

- 测试模型 (v2_test.py / v2_test_s.py)
