## 3️⃣ 项目说明文档（文字版）

### 项目目标

本项目旨在对大语言模型（Qwen3-4B/8B）进行 **增量训练**，结合 **监督微调（SFT）** 与 **强化学习（GRPO）**，实现：

* 对数学推理任务（COT/LaTeX OCR）进行高质量微调
* 保留模型基础能力，同时提升特定任务表现
* 支持增量训练，从上一次训练的 LoRA 权重继续训练

---

### 核心模块说明

1. **模型初始化 (`init_model`)**

   * 加载基础大模型
   * 添加 LoRA 低秩适配层
   * 可选加载 checkpoint 进行增量训练
   * 支持梯度检查点节省显存

2. **SFT 阶段**

   * 使用 `unsloth/OpenMathReasoning-mini` 数据集
   * 数据格式化为系统提示 + 用户问题 + 模型回答（包含推理标记）
   * 训练器：`SFTTrainer` + `SFTConfig`
   * 小 batch 训练 + 梯度累积
   * 支持 SwanLab 回调用于实验追踪

3. **GRPO 阶段**

   * 使用 `DAPO-Math-17k-Processed` 数据集
   * 数据格式化为 prompt + answer
   * 奖励函数：

     * `match_format_approximately`: 检查输出格式
     * `check_answer`: 检查答案正确性
   * 训练器：`GRPOTrainer` + `GRPOConfig`
   * vLLM 采样参数配置生成多样化输出
   * 可保存训练输出到 `outputs/`

4. **训练管理**

   * 显存管理：训练阶段前后释放缓存
   * 支持 checkpoint 保存和增量训练
   * 可配置训练步数、学习率、batch size

5. **推理**

   * 测试训练效果
   * 提供 prompt，输出包含推理过程和答案

---

### 执行流程总结

1. 初始化模型（基础模型 + LoRA + checkpoint可选）
2. 执行 SFT 阶段训练
3. 清理显存
4. 执行 GRPO 强化学习训练
5. 保存最终 LoRA 权重
6. 推理测试验证训练效果
