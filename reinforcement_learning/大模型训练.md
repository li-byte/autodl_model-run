## **1️⃣ 预训练（Pretraining）**

### **概念**

预训练是大模型学习通用语言能力的阶段。目标是让模型对语言有广泛的理解和生成能力，而不针对特定任务。

### **主要技术点**

* **训练目标（Loss）**：

  * **自回归语言模型（Autoregressive LM）**：预测下一个词（如 GPT 系列）
    [
    L = - \sum_{t} \log P(x_t | x_{<t})
    ]
  * **掩码语言模型（Masked LM）**：预测被掩码掉的词（如 BERT）
* **数据规模**：

  * 通常使用**超大规模文本语料库**（网页、书籍、论文等）。
  * 数据去重、清洗、去噪是关键技术点。
* **模型结构**：

  * Transformer 架构是主流（自注意力机制）
  * 参数量从百万到百亿、千亿量级。
* **优化技术**：

  * 分布式训练（Data Parallel + Model Parallel）
  * 混合精度训练（FP16/BF16）
  * 学习率调度（Warmup + Cosine Decay）

### **目标与特点**

* 获得**通用的语言表示能力**。
* 不针对下游任务。
* 对计算资源要求极高。
* 可看作是模型的“基础能力构建”。

## **2️⃣ 微调（Fine-tuning）**

### **概念**

微调是在预训练模型基础上，针对特定任务或领域进行再训练，使模型在特定场景下性能更优。

### **主要技术点**

* **任务类型**：

  * 文本分类、问答、生成任务、代码补全等。
* **数据规模**：

  * 任务相关数据，通常比预训练小得多。
* **微调方法**：

  1. **全量微调（Full Fine-tuning）**：更新模型全部参数。
  2. **参数高效微调（PEFT, Parameter-Efficient Fine-Tuning）**：

     * **LoRA（Low-Rank Adaptation）**：只训练低秩矩阵。
     * **Adapter**：插入小网络。
     * **Prefix Tuning**：调整输入的可学习前缀。
* **优化技巧**：

  * 数据增强（Data Augmentation）
  * 小批量训练
  * 学习率调节（通常比预训练小得多）

### **目标与特点**

* 针对特定任务或领域优化性能。
* 可以显著减少标注数据需求。
* 保留预训练能力，但增强任务特化能力。
* 对算力要求比预训练低。

## **3️⃣ 强化学习（Reinforcement Learning, RL）或 RLHF（Reinforcement Learning with Human Feedback）**

### **概念**

强化学习阶段通常用于**对齐模型输出与人类偏好或特定目标**。在大模型中最典型的应用是 RLHF（GPT 系列采用）。

### **主要技术点**

* **步骤**：

  1. **监督微调阶段（Supervised Fine-tuning, SFT）**：

     * 先用人工标注数据对模型进行微调，使其基础输出质量达到可接受水平。
  2. **奖励模型训练（Reward Model, RM）**：

     * 人类标注不同输出的好坏，训练一个奖励模型 (R(x, y))。
  3. **策略优化（Policy Optimization）**：

     * 使用强化学习算法（如 PPO, Proximal Policy Optimization）：
       [
       \max_\theta \mathbb{E}[ R_\phi(y|x) ]
       ]

       * 模型作为策略 ( \pi_\theta )
       * 奖励由奖励模型提供
* **关键技术点**：

  * **PPO算法**：平衡探索与稳定性
  * **奖励建模**：需要高质量人工标注
  * **安全性控制**：避免模型生成不当输出

### **目标与特点**

* 让模型输出符合人类偏好或特定规则。
* 解决模型生成内容可能偏离目标的问题（alignment）。
* 对标注和训练稳定性要求高。
* 常用在对话模型、推荐系统优化等。

## **4️⃣ 三阶段对比**

| 阶段   | 数据规模      | 训练目标         | 参数更新    | 特点              | 核心技术点                              |
| ---- | --------- | ------------ | ------- | --------------- | ---------------------------------- |
| 预训练  | 极大（TB级文本） | 学习通用语言规律     | 全量      | 构建通用能力          | Transformer, 自注意力, 大规模优化, 分布式训练    |
| 微调   | 小到中等      | 特定任务/领域性能提升  | 全量或PEFT | 提升特定任务效果        | LoRA, Adapter, Prefix Tuning, 数据增强 |
| 强化学习 | 中等        | 对齐输出与目标/人类偏好 | 策略参数更新  | 对齐模型输出，改善安全性和偏好 | RLHF, 奖励模型, PPO                    |

### **5️⃣ 总结差异**

1. **目标不同**：

   * 预训练 → 通用能力
   * 微调 → 任务能力
   * 强化学习 → 对齐与偏好
2. **数据不同**：

   * 预训练 → 海量无标签数据
   * 微调 → 小量任务数据
   * RL → 人类偏好标注 + 模型生成数据
3. **技术手段不同**：

   * 预训练 → 大规模分布式训练
   * 微调 → 参数高效方法
   * 强化学习 → 奖励建模 + 策略优化
